# 立体几何实验室

[在线体验（GitHub Pages，无需登录）](https://captainjike.github.io/solid-geometry/)

GitHub Pages 由 `.github/workflows/deploy-pages.yml` 自动构建和发布。向 `main` 分支推送代码后，Actions 会安装依赖、生成静态站点并部署到上述地址；首次启用时请在仓库 Settings → Pages → Build and deployment 中将 Source 设为 **GitHub Actions**。

网站由「交互实验」与「知识公式」两个主模块组成。交互实验包含 10 道高中立体几何题；知识公式按九个主题整理高中数学主干内容。桌面用侧边目录，手机使用横向模块选择，也可搜索知识点、公式和关键词。

## 知识与公式

知识库包含集合与逻辑、函数与方程、三角函数、平面向量、数列、立体几何、解析几何、概率统计、导数与应用九个模块。每个模块顶部都有独立的公式实验台，可调节两个参数、播放变化动画、读取实时结果，并通过三步推导把图像变化连接到公式。当前实验包括集合区域、二次函数、正弦波、向量数量积、等差数列、固定体积圆柱、直线方程、二项分布和导数切线。

实验下方的知识点统一展示：

- 核心概念与结论；
- 常用公式及公式含义；
- 公式成立的条件；
- 易错提醒与微型例题；
- 关键词，以及可用时跳转到对应的立体几何实验。

搜索会跨全部模块匹配标题、概念、公式、注释和关键词。知识内容集中维护在 `lib/knowledge.ts`，展示与搜索逻辑位于 `components/knowledge-center.tsx`。

## 题目与交互

1. 圆锥展开：调整半径、高度与展开进度；可切换 Blender 视频。
2. 正四棱锥展开：四个侧面绕底边打开，斜高与面积保持不变。
3. 圆台展开：侧面等距展开成扇环；计算结果另计两个底面。
4. 正方体切角：调整切割位置，移开小角，观察增减面积。
5. 正方体动态截面：固定 x+y+z=t 方向，平移切面，显示真实截形及面积曲线。
6. 球的截面：调整切面距球心距离，同时观察圆形截面、直角三角形和面积曲线。
7. 圆锥平行截面：调整切面高度，比较截面积与底面积比例。
8. 绕斜边旋转：直角三角形扫出共底双圆锥。
9. 圆柱与半球组合：拆开观察隐藏的接触圆面。
10. 圆柱面积最值：固定体积，改变半径，联动高度与面积曲线。

圆锥 Blender 视频使用固定 r=3、h=4，时长 10 秒；交互模型可调整参数。其余九题使用浏览器实时几何投影。图形网格用于显示，结果使用解析公式。图形与平面截面示意独立缩放，所有单位均在页面说明。

## 本地运行与验证

```sh
npm install
npm run dev
node scripts/verify-solids.mjs
npx tsc --noEmit
npm run build
```

几何验证覆盖 189 个模型状态、展开面积守恒、切角表面积、121 个正方体截面、球与圆锥截面、双圆锥、组合体与固定体积最值。多边形结果采用精确误差限，曲面网格采用离散化误差限。

原圆锥 `lib/cone.ts` 使用可展圆锥族等距展开，母线长度、边界弧长和曲面面积保持不变。既有验证覆盖 4 组尺寸、7 个展开位置、4096 段数值采样。其 WebMCP `configure_cone` 在圆锥题挂载期间使用同一 React 状态及参数校验。
